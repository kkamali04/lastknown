# Pinned notices for two objc2 0.3.2 crates

The published `objc2-core-foundation` and `objc2-core-services` 0.3.2 archives omit license files.
`LICENSE-UPSTREAM.md` is the complete upstream declaration at the Git revision recorded by both
crate archives. `LICENSE-APACHE-2.0.txt` is the full official text of the selected Apache-2.0 option.
Neither file is edited. `provenance.json` records URLs, hashes and exact crate identities.

The upstream declaration's Apple SDK discussion is preserved. This folder supplies notices;
it does not change any upstream terms. `scripts/bundle_licenses.py` uses it only for the two
exact audited registry releases and keeps their original declared SPDX expression in the manifest.
